# UI再設計の合意事項

## メイン画面

- 明るい緑を主なアクセントにし、白・薄いグレーを基調とする。
- 左側に検索可能な翻訳履歴を置き、終了後も保存する。
- 残りの領域は上に大きな翻訳結果、その下に原文を表示する。
- スクショ翻訳・選択文字翻訳のショートカットを利用できる。

## 設定画面

- 左側のカテゴリ一覧、右側の設定内容、下部の保存・キャンセルという構成。
- 最も重要な設定として「翻訳方式」を配置し、次のどちらかを選択できるようにする。
  - **ローカル PLaMo**: 文字はローカル翻訳。スクショはOCRで原文を取り出してからPLaMoへ渡す。
  - **クラウド Gemini**: スクショの画像を直接Geminiへ渡し、従来の一括翻訳を行う。選択文字はGeminiで翻訳する。
- ローカルモデルは「軽量：0.8B GGUF」「品質優先：2B GGUF」の2種類に限定する。BF16は使用しない。実行ファイルのパス等は高度な設定に置く。
- 配布版はCPU／GPUの両方で実行できる構成とする。利用者のPCの空きVRAM・メインメモリ・対応GPUに応じて、0.8B／2B等のモデルを選べるようにする。
- モデルの選択とCPU／GPUの選択は分ける。自動選択と手動指定を用意し、GPU容量不足時はCPUへの切り替えや軽いモデルの選択を案内する。CPU版とVulkan版のランタイムを同梱する。
- ローカル翻訳でもOCRをクラウドで行う場合は、画像を外部へ送信することを分かるように表示する。
- APIキー・クラウドモデル設定、ショートカット、履歴、ライセンス等の設定をカテゴリ別に整理する。
- UI再設計・履歴・クラウド方式切替・CPU／GPU実行を実装。

## 過去のモデル比較（本実装では評価を追加実行しない）

- 英語・中国語から日本語への翻訳を、同一原文・同一生成条件でGGUF Q4_K_MとBF16の両方に実行する。
- 原文と各モデルの訳文は全文をMarkdownに収録する。
- エージェントは意味の保持を評価し、文章の自然さはユーザーが判断する。
- 方式の初期値は比較結果とユーザー判断を踏まえて検討する。
