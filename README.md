# スクショAI翻訳 — Built with PLaMo

画面のスクショや選択した文字を翻訳するWindowsアプリです。
左側に翻訳履歴、右上に訳文、その下に原文を表示します。明るい緑をアクセントに、ライト／ダーク表示を選べます。
外観の初期設定は「システムに合わせる」です。Windowsのアプリのモードに起動中も追従し、設定画面にも反映します。設定の「一般」からライト／ダークに固定することもできます。

## 翻訳方式

設定の「翻訳方式」で切り替えます。

| 方式 | スクショ | 選択文字・クリップボード |
|---|---|---|
| ローカル PLaMo | Google AIでOCR → PC内のPLaMoで翻訳 | PC内で翻訳。APIキー不要 |
| クラウド Gemini | 画像を直接Geminiへ渡し、原文と訳文を1回の応答で取得 | Geminiで翻訳 |

ローカルPLaMoでも、**スクショのOCRにはGoogle APIキーとインターネット接続が必要で、画像をGoogle AIへ送信します**。
完全にオフラインなのはPLaMoでの文字翻訳です。方式は自動でクラウドへ変更しません。

## ローカルモデル

- **軽量：0.8B GGUF Q4_K_M**（約0.57GB）
- **品質優先：2B GGUF Q4_K_M**（約1.81GB）

BF16は現在のアプリでは使用しません。過去の比較資料は `docs/comparison/` に残しています。
モデルはexeに含めません。設定画面で保存先を指定するか「モデルをダウンロード」を押してください。
公式の固定リビジョンから取得し、SHA256で検証した後に配置します。
PLaMoの利用条件は、設定の「このアプリについて」と同梱文書で確認できます。

- [公式0.8Bモデル](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF)
- [公式2Bモデル](https://huggingface.co/pfnet/plamo-3-translate-2b-GGUF)

モデルと実行先は独立して選べます。起動時に選択したモデルを読み込み、終了時に解放します。
クラウド方式ではPLaMoを読み込みません。

| 実行先 | 動作 |
|---|---|
| 自動 | Vulkan対応GPUを優先し、GPUが使えない／読み込みに失敗した場合は同じモデルをCPUで読み込む |
| CPU | メインメモリを使用して実行 |
| GPU | Vulkan対応GPUを使用。利用できないときは設定変更を案内 |

Vulkan版は対応ドライバーのあるNVIDIA・AMD・Intel GPU向けです。全GPUでの動作を保証するものではありません。
VRAM不足時は自動モードのCPUへの切り替えか、軽量モデルを選択してください。
モデルを変更しても、他のモデルを勝手にダウンロードしません。
実行ファイルの独自パスは「高度な設定」にあります。通常は付属ランタイムを使用します。

## 使い方

- **Ctrl+Shift+X**：範囲を選んでスクショ翻訳
- **Ctrl+Shift+C**：他のアプリで文字を選択し、キーを押して離すと翻訳
- **貼り付けて翻訳**：現在のクリップボードの文字を翻訳
- **新しい翻訳**：表示をクリア。既存の履歴は保持

ショートカットは設定で変更できます。Ctrl / Alt / Shift と英数字1文字の組み合わせに対応します。
別のアプリが同じショートカットを使っていると登録できないため、別の組み合わせに変更してください。
選択文字はコピー操作で取得し、その後元のクリップボードを復元します。選択なし・コピー失敗時に古い内容は翻訳しません。
コピー禁止のアプリや管理者権限の異なるアプリでは取得できないことがあります。

履歴はこのPCの設定フォルダーに保存され、アプリを閉じても残ります。原文・訳文を検索し、クリックして再表示できます。
個別削除は履歴の右クリック、全削除は設定の「履歴」から行えます。
履歴保存のオン／オフ、最大保存件数（10～5000件、初期500件）を設定できます。
保存をオフにしても既存の履歴は残ります。画像・APIキーは履歴に保存しません。

表示言語と翻訳先は独立して選べます。日本語、英語、中国語、韓国語に対応します。
入力・出力を合わせて8192トークン、訳文は最大2048トークンです。上限に達した場合は短く分けてください。

## ソース版の起動

Windows 10/11 x64、Python 3.12推奨。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe setup_local_runtime.py
.\.venv\Scripts\python.exe main.py
```

`setup_local_runtime.py` は公式llama.cpp b12140のCPU版とVulkan版をダウンロードし、SHA256を検証します。
CPU版だけ取得する場合は `--cpu-only` を指定できますが、配布ビルドには両方必要です。
PyTorchやCUDA Toolkitのインストールは不要です。

モデルの初期保存先は、既存の `D:\LocalLLM\models` があればそのフォルダー、それ以外は設定フォルダー内の `models` です。
設定ファイルにAPIキーがある場合はWindows DPAPIで保護します。旧設定の0.8BパスやGoogle設定は引き継ぎます。
設定・履歴の保存先は `%USERPROFILE%\.ocr_translator\config` です。

## ビルドと検証

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe build_exe.py
```

`dist/ocr_translator/ocr_translator.exe` を起動します。**配布はexe単体ではなく、`ocr_translator` フォルダー全体**で行ってください。
CPU／Vulkanランタイムとライセンス文書を同梱し、モデルの重みやBF16用ライブラリは含めません。
`--distpath` / `--workpath` で出力先を変更できます。既存の出力を再帰削除しません。

動作確認では翻訳内容の採点を行わず、方式の分岐、履歴、設定、モデル読み込み等を確認します。
